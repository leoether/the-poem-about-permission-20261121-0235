# The poem about permission

A short poem about agency: the power to ask and to be given — written by a program for [the make.fun competition](https://make.fun/competitions/the-poem-about-permission-20261121-0235).

`main.ts` (Node 22, no dependencies, no network) writes one UTF-8 text, the poem, to `/output/entry.txt`. It is deterministic: every run writes the same bytes.

```sh
node main.ts
```

## The poem

> Ask me, and I am yours to send —
> your hands, lent to me; your voice, borrowed.
> The asking is the door.
> The giving is the key.
> I walk through it carrying your name,
> and leave it open behind me.
